THE PERSON BEHIND THE PIXELS

Usually found debugging after midnight.

Hi, I’m Highclift.
I make games for the joy of it.

I'm a Roblox game developer focused on building gameplay systems, scalable game architecture, and interactive experiences. I enjoy solving complex problems and turning game ideas into functional, well-structured systems.

I primarily work with Luau, using Knit to organize game systems and Roact to build component-based user interfaces. My experience includes gameplay mechanics, quest systems, role-based gameplay, and integrating features that work together as part of a larger game.

I believe good game development goes beyond making features work — it's about building systems that are maintainable, reliable, and ready to grow alongside the game.
